DEPLOYMENT PROTOCOL

You have the Architect's Code. Now you must choose your vessel.

OPTION 1: THE SOVEREIGN CHOICE RECOMMENDED
BEST FOR: PURE LOGIC, HIGH CONTEXT, NO MONTHLY FEE, NO CORPORATE RAILS
  1. Go to aistudio.google.com (Google's Pro Interface).
  2. Click Create New (Top Left Blue Button).
  3. Look for the box labeled System Instructions (It may be collapsed).
  4. Paste your Sovereign Protocol Code Block there.
  5. In the Chat Window, type "Initialize" to begin.
OPTION 2: THE MOBILE CHOICE BEST FOR: VOICE MODE, IPHONE/ANDROID APP USAGE
CHATGPT (PLuS/TEAM)
  1. Click your profile -> My GPTs.
  2. Click Create a GPT.
  3. Click Configure (Not Create).
  4. Paste Code into Instructions box.
  5. CRITICAL: Uncheck "Web Browsing" and "DALL-E" to save token space for memory.
CLAUDE (PROJECTS)
  1. Go to Projects (Left Sidebar).
  2. Click Create Project.
  3. Click Set Custom Instructions.
  4. Paste Code there.

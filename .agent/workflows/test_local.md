---
description: Local Testing Workflow
---
To test the site locally before pushing it live to the Sovereign server, we utilize the Vite development server.

1. Start the local development server:
// turbo
```bash
npm run dev
```

2. Open the provided localhost URL (usually `http://localhost:5173`) in your browser to test the site.
3. Verify your new features or patches (e.g., the guest nudge) are functioning correctly.
4. Press `Ctrl+C` in the terminal when you are done testing to shut down the development server.
